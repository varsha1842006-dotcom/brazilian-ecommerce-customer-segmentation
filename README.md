# Brazilian E-commerce Customer Segmentation

## Project Overview

This project analyzes customer behavior and sales data from a Brazilian e-commerce dataset to identify different customer segments and generate useful business insights.

## Objectives

- Understand customer purchasing behavior
- Analyze order and payment patterns
- Analyze customer reviews and satisfaction
- Explore customer location and product details
- Identify different customer segments
- Generate useful customer insights

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Customer Segmentation

Customer segmentation was performed using the RFM approach:

- **Recency** – How recently a customer purchased
- **Frequency** – How often a customer purchased
- **Monetary** – How much a customer spent

The customers were grouped into different segments based on their RFM scores.

## Project Analysis

The analysis includes:

- Data exploration and cleaning
- Customer analysis
- Sales analysis
- Payment analysis
- Delivery performance
- Review and satisfaction analysis
- RFM customer segmentation
- Data visualization

`Ecommerce_Customer_Segmentation.ipynb` contains the complete Python analysis and visualizations.
